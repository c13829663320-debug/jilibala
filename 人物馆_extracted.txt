叽里呱啦 · 人物馆 功能需求文档（优化版 v1.0）
模块名称：人物馆（Character Hall）
所属平台：叽里呱啦 · BalaBala
模块定位：平台四大核心模块之一（人物 / 场景 / 内容 / 我的），提供预置名人浏览对话 + 自定义人物创建
最后更新：2026-09-22

一、模块定位
「人物馆」是用户进入平台后第一个接触的核心模块。这里陈列着大量已建好的名人 3D 人物形象，用户可以左右滑动浏览、选中一个直接对话；也可以新建自定义人物——上传一张照片生成 3D 模型，写入角色提示词、上传人物 Skill 作为底层人格，即可拥有一个专属数字人。
人物馆里的所有人物（预置名人和自定义人物）都可以：① 直接对话；② 被选入任意场景（如趣味法庭）中扮演角色。

二、平台模块结构
text叽里呱啦平台四大模块叽里呱啦 · BalaBala├── 🧍 人物馆（本模块）│   ├── 预置名人（已建好的 3D 人物，可直接对话）│   ├── 自定义人物（用户上传照片+提示词+Skill 创建）│   └── 人物对话（选中人物后直接聊天）├── 🎬 场景│   ├── ⚖️ 趣味法庭（第一个场景）│   └── 更多自定义场景（后续扩展）├── 📢 内容（广场）│   └── 用户分享、交流、围观的社区空间└── 👤 我的（个人中心）    ├── 我的人物（管理自己创建的人物）    ├── 我的案卷/记录    └── 设置

三、核心功能
功能 1：预置名人浏览与选择
1.1 浏览界面
横向滑动卡片：人物以 3D 半身像卡片形式横向排列，用户左右滑动浏览，类似 Tinder/抖音的切换体验
卡片内容：3D 人物模型（可轻微旋转/呼吸动画）、人物姓名、领域标签（如"法律""科技""文学"）、一句人格简介
分类筛选：顶部可按领域筛选（全部 / 法律 / 科技 / 文学 / 商业 / 娱乐 / 历史 / 哲学）
搜索：顶部搜索框，可按人名搜索
1.2 选中与进入
点击人物卡片 → 进入该人物的对话页（直接开始聊天）
长按人物卡片 → 弹出操作菜单：「对话」「加入场景」「查看详情」
「加入场景」→ 选择一个场景（如趣味法庭），将该人物作为场景中的 AI 角色
1.3 预置名人数量
MVP 内置 20-30 位高质量名人 3D 人物，覆盖法律、科技、文学、商业、娱乐、历史、哲学等领域。每位名人包含：高精度 3D 模型 + 蒸馏好的人格 Skill + 语音音色。
功能 2：人物对话
2.1 对话界面
上半屏：3D 人物实时展示（说话时有表情、口型同步、手势动作）
下半屏：对话记录（气泡形式，用户消息在右，人物回复在左）
底部：输入框 + 发送按钮 + 语音输入按钮（二期）
右上角：「加入场景」按钮（把当前对话的人物选入某个场景）
2.2 对话能力
人物以其绑定的人格 Skill 作为底层思维框架和语言风格回复
支持上下文短期记忆（当前会话内记住之前聊的内容）
回复时 3D 模型同步驱动：表情（根据回复情感）、口型（根据 TTS 语音）、手势（预置动作库匹配）
支持文字输入；语音输入和语音回复为二期功能
功能 3：新建自定义人物
核心入口：人物馆浏览页底部/侧边有「+ 新建人物」按钮，点击进入创建流程。用户可以为自己、为朋友、为任何想做的人创建一个专属数字人。
3.1 创建流程（3 步）
text自定义人物创建流程第1步：上传照片，生成 3D 模型    ├── 用户上传一张正面清晰照片    ├── 调用 Tripo3D API 生成 3D 模型（GLB）    ├── 自动转换为 VRM 格式（支持表情/口型驱动）    ├── 展示生成结果，用户可旋转查看    └── 不满意可重新上传照片生成    ↓第2步：写入角色提示词    ├── 用户输入角色设定描述（如"你是一个毒舌但善良的律师..."）    ├── 也可以用交互式引导（AI 问几个问题，帮用户整理提示词）    ├── 提示词决定人物的说话风格、性格、口头禅    └── 提供"预览"：输入一句话，看人物怎么回复    ↓第3步：上传人物 Skill（可选）    ├── 用户可上传 .skill 文件 / 粘贴 Skill 链接    ├── Skill 作为人物的底层人格和思维框架（比提示词更深层）    ├── 不上传 Skill 则只用第2步的提示词作为人格    └── 确认完成，人物保存到"我的人物"    ↓完成！可直接对话，或加入场景
3.2 各步骤详细说明
第 1 步：上传照片生成 3D 模型
上传区域支持点击选择或拖拽，JPG/PNG，≤10MB
提示："建议上传正面、清晰、无遮挡的照片"
生成中展示加载动画（10-30 秒），分步文案："正在扫描面部特征 → 正在构建 3D 模型 → 正在绑定表情"
生成后展示 3D 模型，可 360° 旋转查看
按钮：「满意，下一步」「重新上传」
技术：Tripo3D API 生成 GLB → 自研转换为 VRM → 模型优化（≤10MB）→ 存 OSS
第 2 步：写入角色提示词
大文本输入框，placeholder："描述这个人物的性格、说话方式、背景故事..."
下方提供"AI 帮我写"按钮：点击后 AI 通过 3-5 个问题引导用户（性格/说话风格/口头禅/典型场景），自动整理成提示词
提供"预览效果"：用户输入一句话，AI 用该提示词人格回复，测试说话风格
提示词长度建议 100-1000 字
按钮：「下一步」「上一步」
第 3 步：上传人物 Skill（可选）
页面说明："Skill 是人物的底层人格和思维框架，比提示词更深入。可选，不上传则只用提示词。"
三种上传方式：  
上传 .skill / .txt / .md 文件
粘贴 Skill 链接（GitHub 等可访问地址）
直接粘贴 Skill 内容文本
上传后校验格式，展示 Skill 摘要（人物名/核心特征）
按钮：「完成创建」「跳过，只用提示词」「上一步」
功能 4：我的人物管理
4.1 入口
「我的」→「我的人物」，或人物馆浏览页中切换到「我的」Tab。
4.2 管理功能
人物列表：展示用户创建的所有自定义人物，网格布局，每个卡片有 3D 预览图、名字、人格标签
对话：点击人物 → 直接进入对话页
编辑：可修改提示词、更换 Skill、重新生成 3D 模型（重新上传照片）
重命名：修改人物名字
删除：二次确认后删除，不可恢复
加入场景：将该人物选入某个场景扮演角色
4.3 数量限制
MVP 每个用户最多创建 5 个自定义人物。达到上限时提示删除旧人物后再创建。

四、人物与场景的关系
核心设计：人物馆和场景是解耦的——人物在人物馆里创建和对话，场景独立运行；但人物可以被"选入"场景，成为场景中的 AI 角色。同一个人物可以出现在多个场景中。

text人物与场景的关系人物馆（人物来源）├── 预置名人（包拯、马斯克、李白...）└── 自定义人物（用户创建的）    ↓ 选入场景（人物的舞台）├── ⚖️ 趣味法庭│   ├── 法官 = 包拯（从人物馆选入）│   ├── 原告律师 = 用户自定义人物A│   ├── 被告 = 马斯克（从人物馆选入）│   └── 证人 = 李白（从人物馆选入）├── 🎤 脱口秀剧场（后续）│   └── 演员 = 从人物馆选入的人物└── ...
选入场景的交互：
在人物馆中长按人物卡片 → 「加入场景」→ 选择场景 → 选择扮演的角色位置（法官/律师/被告等）
在场景中，某个角色位置为空时 → 点击「选择人物」→ 跳转到人物馆选择 → 确认后返回场景
场景运行时，人物使用其绑定的提示词/Skill 人格进行对话和互动

五、关键交互设计
浏览即沉浸：人物馆首页就是 3D 人物卡片横向滑动，用户一进来就看到活的名人在动，而不是静态列表
选中即对话：点击人物直接进入对话，不需要先看详情页再点"开始对话"，降低操作成本
创建极简：自定义人物只需要 3 步（照片→提示词→Skill），每一步都有明确的"跳过"选项，最快 1 分钟完成
Skill 可选：Skill 上传是可选步骤，普通用户只写提示词就能创建人物，降低门槛；高级用户可以上传 Skill 获得更深层的人格
人物可复用：创建好的人物可以反复对话、加入不同场景，一次创建多次使用
左右滑动的仪式感：预置名人浏览用横向卡片滑动，类似翻牌子/选角的体验，增加趣味性
