# 3 分钟真实演示脚本（R5 发布版）

> 目标：3 分钟内让观众理解「和古今中外名人在 3D 世界对话辩论同台」。
> 每段标注：**操作 / 预期画面 / 哇时刻 / 降级备用**。

---

## 0:00–0:30　开屏 + 新手引导（3 步到名人对话）

- **操作**：打开 `https://<域名>`（PWA 已装，秒开）。建昵称、选一个胶囊头像。
- **预期画面**：黑屏 → 品牌 logo 浮现 → 广场 3D 大远景，脚下就是自己的化身。
- **哇时刻**：化身一落地，广场上名人的 3D 半身像在走动，不是静态海报。
- **降级备用**：若首屏 3D 加载慢（>8s），直接念「这是实时 3D，待会儿进去看」，不硬等；网络差时画质自动 low。

## 0:30–1:30　招牌体验：和名人对话 → 法庭辩论

- **操作**：走近「趣味法庭」建筑，选「马斯克」当对手，点开始。
- **预期画面**：法庭 3D 坐席落座 → 名人开场白语音（TTS）→ 输入一句「电动车到底是不是骗局？」→ AI 用第一性原理反驳，天平左右摆动。
- **哇时刻**：打出一张「出示证据」牌，天平明显倒向你，法官口播高光台词；结尾可「高光回放 + 再来一局」。
- **降级备用**：AI 网关慢/超时时，自动切离线知识库回话（offline-brain），不冷场；演示前预热一次对话减少首 token 延迟。

## 1:30–2:15　广场 3D 漫游 + 六大建筑 + 名人偶遇

- **操作**：WASD 在广场漫游，镜头转到六大建筑（法庭/脱口秀/狼人杀/酒吧/健身房/图书馆）。
- **预期画面**：3D 广场环绕，建筑招牌 emoji 悬浮；路过「脱口秀剧场」时名人正在台上讲段子。
- **哇时刻**：偶遇一位正在广场走动的名人化身，点头挥手（emote）打招呼。
- **降级备用**：若模型加载慢，先展示已缓存的广场静态视角，口头说明 3D 人物按需加载。

## 2:15–2:45　多人社交：组队 + 一起开局 + 空间语音

- **操作**：点「创建房间」拿 6 位房间码，把另一位演示者/同事拉进来；两人同处一个 3D 房间。
- **预期画面**：两个化身同框，距离越近对方声音越响（空间语音）；一起「组队开局」进法庭。
- **哇时刻**：对方化身在头顶打出一句「文字喊话」气泡（语音不可用时的回落），且不刷屏。
- **降级备用**：WebRTC 打洞失败自动走 TURN 中继；仍不行则文字喊话兜底，演示话术改为「语音和文字双通道」。

## 2:45–3:00　UGC：一句话造场景 + 分享链接

- **操作**：进「场景工作室」，选模板，把名字改成「周末法庭局」，点发布。
- **预期画面**：生成分享链接 `/studio?scene=<id>`，可发给朋友直接打开。
- **哇时刻**：现场把链接发给第二台设备，点开即入同一 3D 场景——「一句话造个世界，分享即玩」。
- **降级备用**：若发布触发敏感词审核，现场演示「内容已进入 pending_review、暂不公开」——这本身就是安全闭环的加分项。

## 贯穿全程的安全彩蛋（可按需提及）
- 聊天里打一个脏话：现场被替换成 `***`，顶部弹出「内容包含敏感词已替换」toast。
- 连续命中 3 次：自动禁言 5 分钟，顶部红色倒计时浮标提示。
