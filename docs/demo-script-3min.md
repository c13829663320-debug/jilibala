# 叽里呱啦 BalaBala · 3 分钟演示脚本（答辩/R5 路演版）

> **总时长：3 分钟整（180 秒）**。按秒级时间轴分配。
> 表格列：时间段 | 画面/操作 | 旁白/台词 | 预期画面。
> 旁白语速按中文 **约 4–5 字/秒** 控制，每段字数已按该语速校准，口播时不要赶。
> 演示基调：自信、紧凑、有节奏；段间用"切下一站"过渡，不恋战。
> 配色：纯黑底 `#000` + 明黄 `#FFD700` + 青绿 `#00CED1`。

## 演示提示与兜底预案

- **节奏控制**：严格按时间轴走，单段不超时；段间用"切下一站"一句带过。
- **R5 新增亮点**：1:50–2:20 的内容安全闭环是本次演示重点，提前用 `admin / demo-user / muted-user / minor-user` 四个账号预热好状态（见 [`demo-accounts.md`](demo-accounts.md)）。
- **兜底预案**：若某场景实时加载慢 / AI 接口抖动，立即切到对应宣传图（`docs/promo-images/promo-0X.png`）静帧补位口播，时间轴不变。
- **核心三句话反复强调**：① 一个人能开局；② AI 实时生成玩法；③ 一句话造世界——这是和 VRChat 类产品的根本差异；R5 新增④ 好玩又安全（合规闭环）。
- **技术兜底**：提前预热 LLM 与 3D 模型缓存，登录好演示账号并保持后台会话。
- **配套素材**：分镜脚本见 [`demo-video/storyboard.md`](demo-video/storyboard.md)；答辩 Q&A 见 [`defense.html`](defense.html)；演示 PPT 见 [`defense-ppt.html`](defense-ppt.html)。
