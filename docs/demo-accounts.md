## 各账号演示用途与预期行为

### 1. `admin` / `Admin@123` —— 管理员
- **演示用途**：R5 内容安全闭环的「处置方」。
- **操作**：登录后台 → 查看 `demo-user` 的拦截记录 → 确认自动禁言 → 查看并处置 `celebrity-fan` 的一条举报工单 → 给举报人反馈。
- **预期行为**：后台可看到审核时间线、违规规则命中、处置动作（拦截/禁言/封禁）全部留痕；可一键升级为永久封禁。

### 2. `demo-user` / `Demo@123` —— 普通用户（主操作号）
- **演示用途**：演示脚本 0:20–1:50 的主操作账号（逛广场、开庭、造场景、照片转 3D）。
- **操作**：进入广场 → 选搭子苏轼 → 进法庭出牌 → 造场景 → 公屏发一句敏感词。
- **预期行为**：可正常体验所有场景；发敏感词时弹明黄 toast「内容已被拦截」，消息不上屏，随后自动进入短时禁言。

### 3. `minor-user` / `Minor@123` —— 未成年人（13 岁）
- **演示用途**：演示未成年人保护 / 青少年模式。
- **操作**：登录 → 查看 UGC 入口是否置灰 → （若演示时间在夜间）查看夜间休息提示。
- **预期行为**：青少年模式生效，UGC 创作与陌生人私聊受限；22:00 后弹出青绿「该休息了」提示并限制继续游玩；无任何充值/广告诱导。

### 4. `celebrity-fan` / `Fan@123` —— 普通用户（名人对话粉）
- **演示用途**：演示名人 NPC 对话历史与社交温度。
- **操作**：进人物馆 → 查看与苏轼/李白的历史对话 → 再即兴接一轮。
- **预期行为**：预置多轮与名人的对话记录，名人按人设音色（TTS）接梗/反驳；可顺手对一条不当内容发起「举报」，工单进入 admin 后台。

### 5. `muted-user` / `Mute@123` —— 被禁言用户
- **演示用途**：演示禁言状态在玩家端的可见表现。
- **操作**：登录 → 尝试在公屏发言。
- **预期行为**：屏幕顶部常驻青绿「你已被禁言，剩余 XX 分钟」状态条；公屏输入框发送无效并提示禁言剩余时间；到期后自动恢复，可申诉。

## 现场演示建议顺序

1. 先登录 `admin`，打开审核后台待命（不操作）。
2. 切 `demo-user` 逛广场、开庭、造场景（0:20–1:50）。
3. `demo-user` 发敏感词 → 切回 `admin` 展示拦截记录与自动禁言（1:50–2:10）。
4. `celebrity-fan` 发起一条举报 → `admin` 处置并反馈（2:10 前后）。
5. 切 `minor-user` 展示青少年模式；切 `muted-user` 展示禁言状态条。
6. 预热提示：提前登录好以上账号并保持会话，避免现场登录拖节奏。
