01 · 产品价值

痛点：现有社交空间「开不了局」

  • 空旷等人来填：VRChat 类世界需要凑齐真人、自建内容，一个人上线就是冷场。
  • 内容门槛高：想造一个世界要会 3D 建模 + SDK，普通用户被挡在门外。
  • 有社交没玩法： avatar 社交重在表演，缺少可结算、可上头的博弈循环。
  • AI 只是聊天：多数产品把 LLM 当问答框，没把它变成玩法规则与对手。
01 · 产品价值

解决方案 + 目标用户

我们的解法

  • 百位古今名人 AI NPC 随时当对手/队友/观众，单人即开局。
  • 一句话造场景，AI 生成可玩 3D 世界，门槛降到「会说话」。
  • 6 套可结算的博弈玩法，规则由 AI 实时判定。
  • 浏览器 PWA，零安装、可离线。

目标用户

  • 喜欢社交博弈：剧本杀、狼人杀、脱口秀爱好者。
  • 爱知识竞技与文化梗的年轻用户。
  • 想低成本创作、把点子变成 3D 世界的 UGC 玩家。
  • 不想下载大包、点开浏览器就玩的轻用户。

02 · 技术架构

技术架构：monorepo 四层

前端 apps/web

React 18 + Vite 5 + TypeScript；Three.js + React Three Fiber + drei 渲染 3D；WebRTC 距离语音/空间音频；vite-plugin-pwa 离线。

后端 apps/api

Node.js + Fastify 5；@fastify/websocket 承载房间与玩法状态同步；glTF-Transform + draco 压缩模型。

AI 层

StepFun / Evomap LLM：NPC 对话、玩法规则生成、自然语言造场景；Tripo 3D：照片/文本 → 全身 3D；TTS 按人设配音。

数据层

node:sqlite 本地持久化（用户/房间/XP/审核记录）；Redis 会话；glTF 资产库与对象缓存。

03 · 部署运维

部署：Docker Compose 四服务

  • web（nginx）：托管前端静态资源，对外 :8080，反代 /api 与 /wss。
  • api（Fastify）：内网 8787，不直接暴露，承载 REST + WebSocket。
  • coturn：TURN/STUN 中继 WebRTC 距离语音，NAT 穿透。
  • redis：房间会话与实时状态 Pub/Sub。
HTTPS 全站加密WSS 加密长连 coturn WebRTCDocker Compose 一键起栈
03 · 部署运维

运维：备份回滚 + 自动化

可靠发布

  • SQLite 定时备份 + 迁移版本化（backup-migration）。
  • 镜像 tag 化，故障一键 回滚上一版本。
  • 健康检查 /health， unhealthy 自动重启。

CI/CD

  • push/PR 自动跑 npm test + build（GitHub Actions）。
  • 单测 Vitest，每文件独立 DB 隔离。
  • 观测：日志 + 指标 + 发布 checklist 可追溯。
04 · 内容合规 · R5 亮点

审核三级处置 + 禁言封禁

  • 一级 · 拦截：公屏/UGC 敏感词 毫秒级拦截，消息不上屏，明黄 toast 提示。
  • 二级 · 禁言：命中规则自动禁言 10 分钟，玩家端青绿状态条，可申诉。
  • 三级 · 封禁：严重违规管理员一键永久封禁，处置全程留痕可审计。
  • AI 生成内容同样过审：名人发言与 UGC 造场景输出均经安全过滤。
